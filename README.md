### 🌸 Iris Classification

The `Iris_prediction.ipynb` notebook applies deep learning concepts to the classic **Iris dataset**.

The model uses flower measurements to classify flowers into three species:

* Iris Setosa
* Iris Versicolor
* Iris Virginica

### Features

```text
Sepal Length
Sepal Width
Petal Length
Petal Width
```

### Target

```text
Species
```

This is a **multiclass classification problem**.
